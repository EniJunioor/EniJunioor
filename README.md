## 🎟️ Em produção — OTicket

> Plataforma de **venda de ingressos e gestão** para eventos e competições esportivas.

- **Web Admin & ERP** — gestão de eventos, vendas e financeiro para organizadores
- **Checkout & pagamentos** — integração com Mercado Pago, PicPay, Pagar.me e Safrapay
- **App mobile** — React Native + Expo para operação e público
- **Backend** — NestJS, PostgreSQL + Drizzle ORM e Redis
